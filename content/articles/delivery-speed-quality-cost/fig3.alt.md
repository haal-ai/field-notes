Figure 3. Taux de réussite conjointe pour un seul setup (un harness et un modèle). Demandes contradictoires : 62 % quand un seul agent reçoit les deux demandes, 16 % quand deux agents parallèles, séparés, reçoivent chacun une demande, soit un écart de 46 points. Demandes complémentaires : 86 % avec un agent contre 57 % avec deux agents, soit un écart de 29 points. C'est une mesure de réussite, pas de vitesse ni de coût. L'écart mêle le partage d'information et le parallélisme. Source : étude ParallACT ; Claude Code avec Claude Opus 4.8, évalué sur 85 des 155 instances du benchmark.
