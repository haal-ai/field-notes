Figure 1. Cinq couches sont empilées, de haut en bas. (1) La plateforme de bots, qui joue le rôle du client, apporte la mémoire, les tâches planifiées et les canaux. (2) Le harness fait tourner la boucle de l'agent, les outils et le MCP. (3) L'API gateway offre une adresse unique, gère les clés et le routage. (4) L'inference server, par exemple vLLM, gère le KV cache. (5) Le modèle open-weight, ses weights, est chargé sur le GPU. Interfaces : ACP (JSON-RPC sur stdio) entre un client, ici la plateforme, et le harness (usage par extension : ACP est décrit pour éditeur et agent de code) ; une API HTTP compatible OpenAI entre le harness et l'API gateway, puis la même API HTTP entre l'API gateway et l'inference server ; la mémoire GPU entre le serveur et le modèle. Aucun chiffre.
