Figure 4. Six étiquettes, de la preuve la plus forte à la plus faible. (1) Enforcement observé : montre un refus avec un chemin autorisé qui aboutit ; limite : pas tous les cas couverts. (2) Comportement du modèle observé : montre un refus avant tout appel d'outil ; limite : pas un blocage système. (3) Source seulement : montre ce qui est lu dans la documentation ou le code ; limite : non exécuté. (4) Bloqué par compatibilité : le test n'a pas pu tourner ; limite : aucune conclusion. (5) Erreur de fixture ou incertain : le montage est douteux ; limite : à refaire. (6) Sans objet : l'exigence ne s'applique pas ; limite : rien à conclure.
