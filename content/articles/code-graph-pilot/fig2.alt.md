Deux chemins vers une réponse.

Agent seul : question, recherche, lecture d'un fichier, lecture d'un fichier, et ainsi de suite, réponse. L'agent cherche et lit fichier par fichier.

Agent + graphe : question, interrogation de l'index (définitions, appelants, types, routes, impact d'une modification), lecture éventuelle du fichier, réponse. L'agent interroge d'abord l'index, puis lit parfois le fichier quand même.

Le graphe peut ajouter une étape (non testé).
