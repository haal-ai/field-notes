Sept étapes, avec un paquet fictif, exemple-lib. 1 : les mainteneurs écrivent skills/nom/SKILL.md. 2 : le paquet est publié. 3 : pnpm install trouve la skill dans une dépendance directe. 4 : pnpm affiche « Packages awaiting approval » ; c'est un arrêt, en attente d'approval, et rien n'est lié. 5 : pnpm approve écrit l'accord dans pnpm-workspace.yaml, avec par exemple permissions: { exemple-lib: { skills: true } }. 6 : pnpm crée un symlink vers node_modules dans le dossier de skills de l'agent, .claude/skills ou .agents/skills. 7 : l'agent lit la description. Note : pnpm 12.11.0 ou plus ; jusqu'à 3 niveaux sous skills/. Source : pnpm, Agent skills.
