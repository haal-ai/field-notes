Figure 5. Trois projets, trois questions. OpenSandbox : où et comment lancer le code ? Entrée : une API de sandbox (SDK, OpenAPI). OpenShell : quelles règles encadrent l'agent ? Entrée : une politique déclarative d'abord. OpenEnv : quel environnement pour entraîner ou évaluer ? Entrée : une API d'environnement (reset, step, state). Recoupements : OpenSandbox et OpenShell (réseau sortant, secrets). OpenEnv est complémentaire : un environnement peut tourner dans une sandbox. Comparaison de rôles, sans mesure.
