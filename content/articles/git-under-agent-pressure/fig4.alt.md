Figure 4. Tableau à cinq lignes (état en novembre 2026, aucun classement de performance). Colonnes : objets ; déplacement de la branche ; ce qui est sacrifié ou état. GitHub : objets sur replicas à disques locaux et Azure Blob Storage ; cible : objets dans Blob Storage, disque local = cache ; branche déplacée avec un lock par ref ; cible : compare-and-swap par ref (Ref-CAS, quorum) ; aperçu privé limité en novembre 2026. GitLab : Git compatible, calcul sans état sur stockage d'objets partagé, l'agent ne lit que le nécessaire ; déplacement de branche non détaillé dans la source ; bêta privée. Anthropic Scion : changesets (ensembles de changements) dans un write-ahead log ; compare-and-swap sur une ligne de base de données, tests après fusion ; système interne, non proposé à d'autres, « pas un remplacement général de Git ». Cursor (Continuity, dans Origin) : write-ahead log dans un object storage compatible S3, dépôts sur disque = caches ; compare-and-swap sur l'index du log ; statut non précisé dans le billet. Entire : cellules régionales, objets copiés dans au moins deux zones ; compare-and-swap dans une base PostgreSQL ; produit récent (billet du 27 octobre 2026).
